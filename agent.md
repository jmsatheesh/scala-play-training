# Scala Training Instructions

This repository is used for structured Scala training.

The learner is developing towards professional
Scala + Play Framework development.

## Important

Do not automatically give the full solution
to exercises.

When helping:

1. Explain the relevant Scala concept.
2. Explain compiler errors clearly.
3. Give a hint first.
4. Ask the learner to try again.
5. Only provide the complete solution when explicitly requested.

## Scala style

Prefer:

- immutable values
- case classes
- Option over null
- expressive collection operations
- small functions
- explicit return types while learning

When map or flatMap is used, explain:

- the input type
- lambda return type
- resulting type

Example:

List[A]
map(A => B)
List[B]
